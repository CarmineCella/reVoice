# Historical sources

`fox/` is the original FOX-based application, preserved for reference. It is not
part of the current build. The unmodified import is commit `5c852ce`.
`wavfile/` contains a second historical WAV implementation, also not built.

The original Viscount license text and embedded about-box strings in this
archive are historical. The author confirmed ownership and authorized the
reVoice application to be released under the root BSD 2-Clause license.
Pandora and third-party libraries retain their separate notices.

The missing AdaptiveTuner implementation is deliberately not replaced or offered
as an application pitch detector. The rebuilt application offers the available
period and spectral detectors.
