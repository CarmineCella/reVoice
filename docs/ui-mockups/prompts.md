# reVoice UI concept prompts

Three concept mockups generated with the built-in image generation tool.
These propose visual directions; they do not represent changes to the running app.

## 01 — Studio

High-fidelity desktop UI mockup for reVoice, an existing real-time four-voice vocal
harmonizer. Flat, straight-on, entire application window visible, landscape 3:2.
Professional contemporary audio software with graphite surfaces, restrained mint
accent, strong light typography, fine borders, generous spacing and no glow or
decorative glass. Small neutral desktop title bar. Header: reVoice, Custom preset,
Live input, Audio on, Stop audio, Record. Slim left navigation: Studio, Voices,
Morphizer, Pitch detector, Audio / MIDI. Main area shows detected A3 / 220.0 Hz and
a restrained pitch trace above four equal voice cards. Cards show Voice 1–4,
enabled state, intervals 0 / +4 / +7 / +12 st, level, pan, Formant 1.00x and an
advanced edit affordance. Voice controls should look precise and genuinely usable.
Separate bottom mixing strip: Original, Harmony, Morphizer, Reverb, Output, with
clear values and stereo meters. Footer shows 48 kHz, buffer 256, latency 32 ms,
CPU 3%. High-contrast readable text. Use real UI hierarchy; avoid website hero
sections, marketing, fake 3D hardware, decorative graphs and excessive cards.
Do not offer AutoTune, AdaptiveTuner or AI functionality. The image is a design
proposal, not a photograph or a view of source code. No external brand logos.

## 02 — Clear

High-fidelity desktop UI mockup for reVoice, the same existing real-time four-voice
vocal harmonizer, with a distinctly different LIGHT visual direction. Flat,
straight-on full application window, landscape 3:2. Warm white background, ink
typography, subtle neutral separators and a restrained cobalt blue active accent.
Contemporary instrument-like clarity rather than a business dashboard. Header:
reVoice, Custom preset, Live input, Start / Stop, Record. Horizontal navigation:
Harmony, Morphizer, Pitch detector, Audio / MIDI. A compact pitch ribbon near the
top reads A3, 220.0 Hz, A major and Custom chord. Below it, four generous vertical
channel strips labeled Voice 1–4 show intervals 0 / +4 / +7 / +12 st, level faders,
enabled switches, pan controls and Formant 1.00x. A fifth narrow master strip
shows stereo output meters. Lower control shelf groups Original, Harmony,
Morphizer and Reverb mix. Small context inspector provides grain envelope Hann,
cycles Auto, detector Period, key A and scale Major. Footer: 48 kHz, buffer 256,
latency 32 ms, CPU 3%. Large legible values, aligned labels, precise controls,
minimal shadows. Avoid generic web dashboard cards, oversized headings, heavy
gradients, skeuomorphic equipment, decorative waveforms and external logos.
No AutoTune, AdaptiveTuner, AI or new DSP features. This must look like polished
desktop music software with a clear mixer-focused layout.

## 03 — Live

High-fidelity desktop UI mockup for reVoice, the same existing real-time four-voice
vocal harmonizer, as a performance-focused interface. Flat straight-on full
application window, landscape 3:2. Near-black ink background, warm amber active
accent, high-contrast ivory typography, minimal visual noise and very generous
touch targets. Avoid the neon gaming look. Header: reVoice, Live, Custom preset,
Live input, Stop audio, Record. The dominant center is four wide horizontal voice
rows: Voice 1 / 0 st, Voice 2 / +4 st, Voice 3 / +7 st, Voice 4 / +12 st. Each row
has a large enabled switch, large interval value, long level slider, readable pan
value and a compact Edit button for deeper settings. A clear right-hand master
column shows A3 / 220.0 Hz, stereo output meters and a large Output control.
A lower performance strip offers clear Bypass and Freeze buttons and four
compact mix controls labeled Original, Harmony, Morphizer, Reverb. Bottom
navigation or disclosure: Voice detail, Morphizer, Pitch detector, Audio / MIDI.
Footer: 48 kHz, buffer 256, latency 32 ms, CPU 3%. This is a quiet, mature,
stage-readable instrument UI with fewer controls on its main screen, not a
replica of a physical rack. No website marketing, glow, photos, external logos,
AutoTune, AdaptiveTuner, AI or invented audio processing features.

## Refinement prompts

### Studio refinement

Preserve the Studio screenshot's composition, spacing, mint/graphite palette,
typography, four voice cards, navigation, pitch plot and all existing controls.
Flatten the surface treatment: remove glossy background gradients, raised/beveled
control edges and texture; use solid graphite surfaces and subtle 1-pixel borders.
In the Morphizer mix section only, replace the invented Tone control with the
existing parameter labeled Pitch ratio and display 1.00x below it. Keep the
Original, Harmony, Morphizer, Reverb and Output mixing sections. Render crisp,
contemporary desktop music software, not physical hardware. Do not add controls.

### Live refinement

Preserve the Live screenshot's composition, four wide voice rows, interval values,
output meters, transport, Bypass/Freeze and lower mix controls. Replace every
serif label, including reVoice and all voice names and pitch text, with a clean
contemporary neutral sans-serif. Remove all gloss, glows, gradients, bevels,
shadows and raised knob bodies. Use solid near-black/graphite surfaces, fine gray
borders, ivory readable text and solid restrained amber accents. Draw rotary
controls as thin flat vector arcs with pointers, not physical knobs. Make Bypass
an inactive outlined button, so all voice controls are visually available. Keep
large readable values and generous touch targets. No added features or external
logos. The goal is a precise contemporary live-performance instrument UI.
